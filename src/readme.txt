Some features of the website only work with a server running.
Assuming you have python installed, you can use it as a lightweight server.

Navigate to the root directory src in a terminal and type: python -m http.server 8000

This will start the server running and allow you to use the full site.
access the site by using entering http://localhost:8000/index.html into your browser


If you do not have python, you can open an individual pages by clicking on them from file explorer.
Note: The navigation bar will not work correctly if you load the site using this methodology.
